# /feature Workflow

This workflow uses the `development` skill.

## Steps
1. Read the instructions in the [development skill](../skills/development/SKILL.md).
2. Execute the `/feature` command flow:
   - Read `.agent/memory/architecture.md`, `conventions.md`, and `features.md` for context.
   - Plan the implementation approach (files to create/modify, components, data flow).
   - Implement the feature following project conventions.
   - Verify the implementation with basic checks.
   - Auto-update memory if allowed: add to `features.md`, update `architecture.md` if structural, log in `history.md`.
